# modbus-studio (backend)

Python package for modbus-studio: an open-source
Modbus master you use from the browser. It polls Modbus TCP, RTU and RTU-over-TCP devices,
decodes their registers and shows the raw traffic.

```bash
pip install modbus-studio
modbus-studio            # http://127.0.0.1:8000
modbus-studio-sim        # slave simulator: TCP :5020, RTU over TCP :5021
```

Documentation, Docker image and issue tracker: <https://github.com/electrolabopen/modbus-studio>.

modbus-studio is an independent project, not affiliated with Witte Software.
